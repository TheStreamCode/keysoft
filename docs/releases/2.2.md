# Keysoft 2.2

Android versionCode: 120

## Highlights

- The settings support entry now links to GitHub Sponsors (`github.com/sponsors/TheStreamCode`) instead of Buy Me a Coffee, relabeled "Sponsor on GitHub" / "Sponsorizza su GitHub" with a heart icon.
- Device-driven language and theme: the app follows the device language (Italian devices use Italian, every other language falls back to English) and the device light/dark theme automatically. Language detection now resolves synchronously on the first render, removing the brief English flash on Italian devices; the init fallback defers to system detection instead of forcing Italian.
- Dictionary cleanup: removed 492 unreferenced translation keys from the Italian and English dictionaries (generic networking/cloud/sync/upload/file filler plus other unused keys), roughly halving both files from 1065 to 573 keys. No user-facing string changed.
