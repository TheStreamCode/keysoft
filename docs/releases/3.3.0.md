# Keysoft 3.3.0

Android production target: versionCode 129.

Keysoft 3.3.0 packages a repository-wide security and maintainability review without changing the visible design, icons, assets, vault format, permissions, or offline-first product behavior.

## Highlights

- Hardened untrusted KDF and backup inputs with explicit resource limits.
- Made encrypted storage mutations persist before updating in-memory state and limited reset to Keysoft-owned records.
- Removed the fully rendered but hidden legacy Settings tree and other unused source and configuration files.
- Aligned Expo SDK 57 dependencies, removed unused direct dependencies, and patched the critical transitive `shell-quote` advisory.
- Added deterministic, least-privilege CI with frozen installs, full-SHA actions, coverage tests, Expo health checks, and critical dependency auditing.

## Security And Reliability

- Production logs no longer include diagnostic error objects that might expose sensitive context.
- Backup secrets are cleared from UI state and temporary export files are removed after sharing.
- Verifier comparisons use the constant-time helper.
- Preference defaults are preserved recursively and callers receive defensive copies.
- Failed preference writes no longer apply runtime screenshot, auto-lock, or clipboard behavior that was not persisted.
- Regression tests cover storage failures, scoped reset, KDF and backup bounds, and secure-random limits.

## Repository And Documentation

- Added one-command verification, deterministic Bun and Node versions, CODEOWNERS, EditorConfig, environment-variable guidance, and professional GitHub automation.
- Updated the public overview, architecture, security, development, release, and AI-agent contributor documentation.
- Kept all existing design and visual assets unchanged.

## Verification

- Formatting, TypeScript type-checking, and linting pass.
- 29 Jest suites and 189 tests pass.
- Expo Doctor passes 20 of 20 checks.
- The critical-severity dependency audit passes.
- The Android Expo bundle exports successfully.

## Deployment Boundary

Keysoft 3.1.0 build 128 completed on EAS but was not submitted to Google Play. Keysoft 3.3.0 build 129 is the intended production artifact. Google Play submission remains a separate manual release step.
