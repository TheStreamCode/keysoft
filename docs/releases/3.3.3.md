# Keysoft 3.3.3

Source release: 2026-11-01.

Android production target: versionCode 134.

This release upgrades the runtime toolchain and addresses the release quality findings from
Google Play. It does not change the KS1/KS1-PW1 payload layouts, storage keys, existing vault
KDF parameters, Android permissions or the offline-only operating model.

## Toolchain

- Upgrades Expo SDK 57 to SDK 58 and React Native 0.86 to 0.88.1.
- Aligns Expo modules, React, React DOM, Jest, Jest Expo, React Native Gesture Handler,
  Reanimated, Screens, Safe Area Context and Worklets through `expo install --fix`.
- Uses Android Gradle Plugin 9 through the SDK 58 toolchain. This addresses the Play Console
  recommendation to upgrade AGP for R8 optimization.
- Migrates the bundled license read from the legacy `readAsStringAsync` call to the Expo
  FileSystem `File` API.
- Updates the strict TypeScript API baseline introduced by React Native 0.87/0.88.

## Release quality findings

- The edge-to-edge deprecation warning originates in React Native 0.88 and
  `expo-image-picker` internals. The app already suppresses the deprecated status-bar color
  and translucency props on Android 15 and later. No app-level workaround is applied because
  the remaining calls are dependency code.
- The network-bitmap warning is caused by Fresco in React Native and Glide in
  `expo-image-loader`/`expo-image-picker`, not by a remote image in Keysoft. Profile avatars
  remain local files.
- The R8 warning is addressed by the AGP 9 toolchain upgrade. The previous build already used
  R8 full mode with shrinking, optimization and obfuscation enabled.
