# Keysoft 3.0.2

Android versionCode: 126 (EAS production remote version target)

## Highlights

- Enables optimized R8 processing and Android resource shrinking for a smaller, more efficient production app bundle.
- Keeps the native Argon2 bridge and implementations protected from shrinking so release-grade PIN login retains its existing security behavior.
- Maintains the Expo SDK 57 and React Native 0.86 supported Android toolchain instead of forcing an unsupported standalone Android Gradle Plugin upgrade.
- Documents Google Play's dependency-level edge-to-edge and bitmap findings without adding unused network image infrastructure.

## Android Build Changes

- Release builds use `proguard-android-optimize.txt`.
- `minifyEnabled` and `shrinkResources` are enabled together.
- AGP 8.12 optimized resource shrinking is enabled through `android.r8.optimizedResourceShrinking=true`.
- The configuration plugin fails the native generation step if the expected Gradle template changes, preventing silent loss of the optimization.

## Verification

- Config regression tests cover ProGuard replacement, idempotency, unexpected templates, optimized resource-shrinker properties, and plugin registration.
- The generated Android release project is checked for optimized R8, resource shrinking, and Argon2 keep rules before EAS upload.
- The EAS production artifact must include `mapping.txt` and pass native PIN/Argon2 smoke testing through Google Play internal testing before production rollout.

The Google Play submission remains manual. Edge-to-edge and bitmap recommendations may remain visible while the referenced APIs are still compiled into supported React Native/Fresco/Glide dependencies.
