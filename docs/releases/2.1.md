# Keysoft 2.1

Android versionCode: 110

## Highlights

- Faster password unlock on all devices: Argon2id now uses the OWASP minimum parameters (19 MiB / t = 2 / p = 1) instead of the heavier 64 MiB / t = 3, while staying within OWASP guidance.
- Transparent, non-destructive post-login KDF upgrade: legacy vaults (PBKDF2 or the old heavy Argon2 parameters) are rekeyed to the current Argon2id parameters on the next successful password login; on any failure the vault stays on its previous working key.
- Removed cascading re-renders by memoizing every context value. The alert provider no longer reloads the whole password list whenever a dialog opens or closes.
- Rebuilt the Notes screen on React 19 `useDeferredValue` with derived state, removing redundant state, per-keystroke filtering, and the artificial pagination delay.
- UI/UX and accessibility: theme tokens replace hardcoded colors (fixing dark-mode contrast), more accessibility roles/labels, larger touch targets, and a new top-level error boundary with a recoverable, themed fallback.
- Tooling: aligned all `expo-*` packages to the exact Expo SDK 55 pins and migrated linting to ESLint 9 (flat config).
