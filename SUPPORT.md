# Support

## Where to get help

- **Usage questions and workflows:** GitHub Discussions on this repository.
- **Product assistance:** email [keysoft@mikesoft.it](mailto:keysoft@mikesoft.it) for usage questions
  and problems with the published Android app.
- **Bug reports and reproducible defects:** GitHub Issues using the bug report form.
- **Security problems:** follow `SECURITY.md`, never a public issue.
- **Google Play problems** (billing, store listing, installation errors reported by the store):
  use Google Play support when the problem is on the store side.

## Before asking

1. Check the README troubleshooting section.
2. Search existing issues.
3. Reproduce on the latest Google Play release with a clean configuration.

## What support covers

This is a free, maintainer-run project. Support covers defects in the latest release and
questions about documented behavior. It does not cover customized builds, device
modifications, or recovery of vault data when the master PIN and backup passphrase are lost.

Never include vault contents, PINs, encryption keys, exported backups, or signing material in a
support request. The maintainer cannot recover a locked vault and does not need its contents to
answer a support question.

## Response expectations

Best effort, usually within a week. Reports without version information or a reproduction may be
closed with a request for details.
